## Design Direction

Visual style:

- High contrast.
- Warm but not overly decorative.
- Music and place-based identity.
- Large readable typography.
- Clear cards and timelines.

Avoid:

- Overly bureaucratic grant-application tone.
- Too many tiny charts.
- Dense PDF-like text.
- Color-only distinctions.

## Build Recommendation

Use a static site first:

```text
index.html
styles.css
script.js
data/*.json
public/images
public/documents
```

This keeps the project easy to maintain and deploy through GitHub + Netlify.
