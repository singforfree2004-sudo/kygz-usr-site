# ESG / CSR 合作洽詢表單規格

建立日期：2026-06-29

## 表單目的

這份表單不是正式提案書，也不是贊助申請表。目的只是讓對「跨樂尬陣」ESG / CSR 合作有興趣的企業、基金會、學校或地方單位，用很低的填寫門檻留下初步聯絡線索，後續再由 Jay 或團隊主動聯絡討論。

## 表單名稱

跨樂尬陣 ESG / CSR 合作洽詢表單

## 表單說明

感謝您對「跨樂尬陣：南流西起共融藝起來」的關注。請簡單留下您的合作想法與聯絡方式，我們會再與您討論合適的 ESG、CSR、員工參與、地方共創或文化內容合作方式。

## 欄位

| 題目 | 題型 | 必填 | 說明 |
| --- | --- | --- | --- |
| 單位 / 公司名稱 | 簡答 | 是 | 外部單位識別用。 |
| 聯絡人姓名 / 稱呼 | 簡答 | 是 | 方便後續聯絡。 |
| 聯絡方式 | 簡答 | 是 | 可填 Email、電話或其他慣用聯絡方式。 |
| 想先和我們討論的事情 | 詳答 | 是 | 可簡單寫 ESG / CSR、員工參與、地方文化走讀、青年培力、活動展演、年度合作等方向，不要求正式提案。 |
